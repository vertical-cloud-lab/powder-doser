# Chain test plan, v2 (vertical twin chain)

What the rig has to answer: **can two #35 chains in vertical planes carry 13 loaded carriages round four 32T corners in step, stop each one at the station repeatably, and can the station dock, tilt, dose and undock a module with its powder staying in between doses?** Each test lists what to measure, how, and the pass mark. Numbers in *italics* are predictions from the CAD checks ([`checks/`](checks)), the simulations ([sim/README.md](sim/README.md)), the [gear-mesh study](../gear-mesh/README.md) or the [auger-leakage study](../auger-leakage/README.md), so a result far from them means the model or the build is wrong.

Run the tests in order. T0-T2 take an afternoon and need no electronics beyond the driver. Log everything with [`test/chain_rig.py`](test/chain_rig.py) (CSV under `runs/`; `--sim` for a dry run), commit the CSVs, and post a summary in [#128](https://github.com/vertical-cloud-lab/powder-doser/issues/128).

**Run direction.** The machine runs with the bottom run travelling toward -y (clockwise seen from the back, `RUN_DIRECTION = -1`). Every lap turns each module once about its own axis, which acts like one auger revolution: this way round it pulls powder back from the outlet, the other way it pumped about one revolution's dose out per lap in the leakage study's proxy. A positive index in `chain_rig.py` always means the machine's direction.

## What the results decide

- **T3 sets the station's capture range.** The approach fork, the conical locating pins and the seek all assume the carriage stops within about 1 mm. If the return spread is several mm, the station needs a locator (a V-notch in the tongue and a spring plunger in the hold-down) before the dock.
- **T1 and T9 say whether the corner shafts keep the chains in step.** Each shaft carries a front and a back sprocket, so the chains can only drift apart if a sprocket slips on its shaft. If one does, the fix is a flat under each set screw or a keyed back sprocket.
- **T4 and T6 say whether the hold-downs and snap hooks are right**, and T6a-d whether the dock holds the mesh: if the magnet is weak (T6a) or docks park (T6b), the station can't dose reliably.
- **T7 and T8 decide the dose protocol and the run direction on real powder**, and whether an open outlet survives a lap of rolling and hanging upside down. If it doesn't, the module needs a cap before anything else on this rig matters.

## Logged columns

`run, utc, cmd, module, target_steps, pos_steps, move_s, index_edge_steps, alarm, dial_mm, tilt, revs, rpm, taps, hold_s, reverse_revs, auger_current_ma, dose_g` (blank where a command doesn't use them). A step is 1/4000 of a sprocket turn (CL86T DIP set to 4000 pulses/rev), 0.076 mm of chain. One module is a quarter turn of the 32T sprocket, exactly 1000 steps.
