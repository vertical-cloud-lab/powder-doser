# Data Assimilation and Parameter Estimation for a Low-Cost Powder Doser: A Literature-Grounded Technical Assessment

## Q1. Whitehead's Research and What Transfers

### 1a. Continuous Data Assimilation and Parameter Learning

Jared P. Whitehead's data-assimilation research centers on the Carlson–Hudson–Larios (CHL) algorithm and its extensions, which learn unknown parameters of a chaotic system online from partial observations. The CHL method augments the Azouani–Olson–Titi (AOT) nudging framework: a model copy is continuously nudged toward observed data through a feedback-control term, and the residual error that remains when parameters are incorrect provides the signal for parameter recovery (carlson2108dynamicallylearningthe pages 2-4). Specifically, when parameters are correct and nudging is sufficiently strong, the assimilated state synchronizes with the true state; with incorrect parameters, a persistent finite error remains, and that error supplies the updating direction (carlson2108dynamicallylearningthe pages 6-8). For the Lorenz system, convergence to the correct parameters is proven under conditions of dissipativity (bounded absorbing-ball dynamics), sufficiently large nudging gains, and a non-degeneracy condition requiring that the observed-state mismatch remain informative at update times (carlson2108dynamicallylearningthe pages 6-8).

Pachev, Whitehead, and McQuarrie (2022) extended CHL to concurrent multi-parameter learning on the Kuramoto–Sivashinsky equation. Their framework uses an orthogonality condition that cancels the residual forcing in the observable-error equation, yielding exponential decay of the observable error at rate μ. For multiple parameters, this single equation is underdetermined, so additional constraints or sensitivity directions are required. Observation density is encoded by an interpolation operator I_h, with smaller h corresponding to resolving more relevant scales (pachev2022concurrentmultiparameterlearninga pages 3-5, pachev2022concurrentmultiparameterlearning pages 3-5).

Newey, Whitehead, and Carlson (2025) recast the CHL update as Newton's method applied to the long-time assimilation error E(c) = ½||I_h(v(c)−u)||². They showed that Levenberg–Marquardt (LM) performs similarly to CHL/Newton for a single parameter but generalizes much better to multiple parameters, reducing the error by a factor of three in multi-parameter experiments on modified KSE (newey2025modeldiscoveryon pages 24-29, newey2025modeldiscoveryon pages 9-13). The LM regularization (W^T W + λI)^{−1} stabilizes ill-conditioned or poorly identifiable directions (newey2025modeldiscoveryon pages 13-19). The paper uses a single real-time simulation and updates parameters as data arrive, contrasting with ensemble or batch methods (newey2025modeldiscoveryon pages 1-5). However, direct comparisons with stochastic/ensemble methods are not provided in the paper; these are mentioned only as future directions (newey2025modeldiscoveryon pages 24-29).

**Assumptions that survive translation to this rig:**

- *Dissipativity*: The powder doser's cup-mass dynamics are bounded and dissipative (mass accumulates monotonically up to a target; balance lag decays exponentially). This assumption holds naturally.
- *Observation density*: The 5 Hz balance stream observes a single scalar with ~0.16 s lag. This is far sparser than "continuous observation of multiple state components." CHL's convergence proofs assume access to enough observed components to enforce synchronization; with one lagged scalar, the nudging gain cannot directly enforce synchronization of unobserved states (screw inventory, lip reservoir, in-flight mass).
- *Synchronization*: The hybrid start/stop dynamics and threshold-triggered halts break continuous-time flow. The CHL "relax then punch" strategy requires the model to settle to a quasi-steady mismatch between parameter updates, but the powder doser's operational runs last only 30–120 s with abrupt state changes (newey2025modeldiscoveryon pages 5-9).
- *Non-degeneracy*: For afterflow parameters to be identifiable via CHL, the observed error must carry information about AF₀ and τ_af, which it does only at halt events—not during continuous flow.

**Verdict**: The CHL/LM framework's most transferable insight is that a deterministic optimizer operating on a long-time mismatch functional provides a computationally cheap, derivative-based alternative to ensemble methods. However, the single-scalar, lagged, 5 Hz observation, short run duration, and hybrid dynamics mean that the formal synchronization and convergence guarantees do not apply. LM's regularization of ill-conditioned multi-parameter directions is directly useful for the proposed MAP fit.

### 1b. Bayesian Inversion in Small-Data, High-Uncertainty Settings

Whitehead's tsunami work (Ringer et al. 2021; Paskett et al. 2024; Wonnacott et al. 2024) demonstrates Bayesian inversion for estimating earthquake or landslide parameters from sparse, uncertain historical observations using expensive forward models. The framework assigns prior distributions informed by expert knowledge and instrumental records, constructs observation likelihoods from uncertain anecdotal accounts (wave arrival times, heights, inundation lengths) with explicitly modeled error distributions (skew-normal, normal), and samples the posterior via random-walk Metropolis–Hastings MCMC over 200,000+ forward simulations (ringer2021methodologicalreconstructionof pages 1-2, wonnacott2024methodologicalreconstructionof pages 7-9, paskett2024ataleof pages 3-5). The open-source `tsunamibayes` Python package implements this pipeline and is designed so that assumptions can be changed directly in code (ringer2021methodologicalreconstructionof pages 1-2).

Key methodological features that transfer:

- **Explicit uncertainty modeling**: Each observation type gets its own distributional model rather than assuming additive Gaussian noise everywhere. For the doser, this supports using Student-t or mixture likelihoods for slug/clump arrivals.
- **Low-dimensional parameterization**: The tsunami studies deliberately keep parameter spaces small (6–9 parameters) to make MCMC tractable with expensive forward models (ringer2021methodologicalreconstructionof pages 4-7, paskett2024ataleof pages 1-3). The doser's 3–5 parameters are well within this range.
- **Prior construction from sparse evidence**: Landslide priors are built from only 25 published events (wonnacott2024methodologicalreconstructionof pages 5-7). Similarly, per-powder priors can be constructed from a handful of calibration sessions.
- **Model comparison**: Paskett et al. (2024) compare competing fault hypotheses via posterior support (paskett2024ataleof pages 1-3), directly applicable to comparing constant vs. history-dependent afterflow models.

**Assumptions that differ**: The tsunami forward model is deterministic (shallow-water PDE), continuous, and expensive (~minutes per evaluation). The doser model is cheap (~ms), stochastic (granular clumps), and discontinuous (start/stop events). These differences favor full posterior sampling for the doser more than for the tsunami problem, since forward evaluations are trivially cheap.

## Q2. Method Fit: Comparing Estimation Approaches

### MAP with Autodiff and a Gaussian Prior as 4D-Var

A single-run MAP fit with automatic differentiation through a deterministic simulator, penalized by a Gaussian prior on parameters, is mathematically equivalent to strong-constraint 4D-Var with a background term (ebtehaj2013onvariationaldownscaling pages 20-22, frion2026addaamodular pages 4-5). The 4D-Var cost function combines a background/prior term ||θ − θ_b||²_{B⁻¹} (which is Tikhonov regularization with the prior covariance B as the regularization operator) with accumulated observation misfits over the assimilation window (ebtehaj2014variationaldataassimilation pages 3-6, freitag2013synergyofinverse pages 1-4). If process noise or model-error terms are added as additional unknowns, the formulation becomes weak-constraint 4D-Var (frion2026addaamodular pages 4-5).

The Laplace approximation—approximating the posterior as Gaussian centered on the MAP estimate with covariance given by the inverse Hessian—is adequate when the posterior is unimodal and approximately quadratic. For a 30–120 s run with only 2–4 parameters, this is often reasonable but must be verified. Under Gaussian error assumptions, MAP and the posterior mean coincide for linear problems, but nonlinear dynamics generally produce non-Gaussian posteriors (frion2026addaamodular pages 4-5, lorenc2003modellingoferror pages 12-14). Profile likelihood analysis provides a practical check: if profiles are approximately parabolic, the Laplace approximation is adequate; if they are asymmetric, flat, or boundary-seeking, it is not (maiwald2016drivingthemodel pages 5-7, raue2009structuralandpractical pages 2-3).

### Recommendation

For a single 30–120 s calibration run, the **differentiable Kalman-filter marginal likelihood** (prediction-error method) is the strongest first production estimator. ## Q3. Identifiability and Experimental Design of the Calibration Run

### Observability Structure

The feed factor φ is observable from any flowing segment: the balance accumulation rate during flow is approximately φ × (RPM), so multiple seconds of steady flow at known speed suffice. The afterflow parameters (AF₀, τ_af) are observable only at halts, and the data show that afterflow also depends on run duration and lip/screw inventory, meaning these are not pure stop-response parameters. With one scalar sensor at 5 Hz, the Fisher information matrix for (φ, AF₀, τ_af) jointly will be rank-deficient unless the calibration run includes multiple halts at different flow conditions.

### Profile Likelihood for Identifiability Assessment

Profile likelihood is the recommended primary identifiability diagnostic. For each parameter of interest, it is varied across a range while all other parameters are re-optimized, producing a curve that reveals practical identifiability (finite confidence interval), structural non-identifiability (flat profile), or parameter compensation (coupled parameter changes that preserve fit quality) (maiwald2016drivingthemodel pages 5-7, wieland2021onstructuraland pages 4-7, raue2009structuralandpractical pages 2-3). Flat or weakly bounded profiles expose sloppy parameter directions that local Hessian methods miss (maiwald2016drivingthemodel pages 2-3). Profile likelihood also reveals when parameters are compensating for structural model error rather than measuring something physical: if the compensating parameter trajectory along the profile is physically implausible or if residual patterns change systematically, the model is absorbing misspecification (murphy2024implementingmeasurementerror pages 9-11).

### Designing the Single Calibration Run

Based on Fisher-information and D-optimal design principles (ayres2609parameteridentifiabilityof pages 20-21, ayres2609parameteridentifiabilityof pages 9-12), the calibration run should:

1. **Include 6–10 start-stop segments** to provide multiple independent afterflow observations. Each halt is essentially one "experiment" for (AF₀, τ_af); with only 2–3 halts, these parameters will be practically non-identifiable.
2. **Use at least 3 RPM levels** (e.g., 15, 45, 75 rpm) to separate φ from RPM-dependent effects and to span the afterflow model A = AF₀ + τ_af × flow.
3. **Vary segment durations deliberately** (some short, ~2–5 s; some long, ~15–30 s) to expose the history/lip-inventory dependence identified in the data.
4. **Hold tilt and tapping fixed** in the first protocol to reduce the parameter count. Only add tilt variation after the base model is identifiable.
5. **Use commanded stops** (not threshold-triggered) so the halt timing is a known input rather than a stochastic function of the estimated state.
6. **Allow ≥ 1 s of settled balance readings** after each halt before restarting, to cleanly observe the afterflow transient.

### Number of Concurrent Parameters

With this design, 2–3 parameters (φ, AF₀, and optionally τ_af) can realistically be estimated concurrently. Adding a fourth parameter (e.g., a lip-inventory decay constant) risks producing sloppy, compensating combinations. The sloppiness diagnostic is the eigenvalue spectrum of the Fisher information matrix or the Hessian at the MAP: if eigenvalues span several orders of magnitude (log-uniformly spaced), the model is sloppy and only stiff combinations are constrained by data (maiwald2016drivingthemodel pages 5-7). In systems biology, this is ubiquitous and is addressed by reparameterizing to stiff eigenvector combinations or by fixing sloppy directions at prior values.

### Detecting Compensation for Model Error

If τ_af varies substantially between datasets (as observed: 0.28 s to 1.07 s), this signals that the linear afterflow model A = AF₀ + τ_af × flow is absorbing history-dependent or nonlinear effects. The profile likelihood of τ_af will be broad, and the compensating parameter trajectories will show AF₀ and τ_af trading off. The remedy is either to extend the model (add a history-dependent reservoir term) or to accept that afterflow is described by a per-run effective value rather than a material constant.

## Q4. Priors, Drift, and Storage

### Setting and Inflating Prior Variance

The stored per-powder parameter estimates should be treated as priors for subsequent sessions, not constants. Several approaches to specifying and inflating prior variance are relevant:

**Random-walk parameter models**: The simplest approach models log(φ) as a random walk with variance growing linearly with elapsed time or dispensed mass: Var(log φ_{t+Δt}) = Var(log φ_t) + σ²_drift · Δt. The drift variance σ²_drift can be estimated empirically from replicated sessions. Time-varying parameter models with random-walk evolution are standard in econometrics and signal processing (onat2019anoveland pages 1-2).

**Hierarchical Bayesian models**: With multiple powders and sessions, a hierarchical structure population → powder → lot → session decomposes the total variance. Population-level hyperparameters encode "typical" feed-factor range and typical session-to-session drift for any powder; powder-level parameters capture material-specific means; session-level parameters capture the current operating conditions. This is the natural long-term architecture but requires data from multiple powders and sessions before the hierarchy is estimable.

**Empirical Bayes across a multi-powder database**: After accumulating calibration records from many powders, the population-level distribution can be estimated and used as an informative prior for a new, uncharacterized powder. This is analogous to the tsunami work's use of published landslide measurements to construct empirically informed priors (wonnacott2024methodologicalreconstructionof pages 5-7).

**Material-property-predicted priors**: Multivariate models using PLS regression can predict feed factor from measured powder properties. Bostijn et al. (2019) used 25 material-property descriptors (including bulk density, tapped density, Hausner ratio, d_v50, compressibility) to predict maximum feed factor (FF_max) and feed-factor decay with fill level (FF_decay) for a twin-screw feeder (bostijn2019amultivariateapproach pages 6-10, bostijn2019amultivariateapproach pages 1-6, bostijn2019amultivariateapproach pages 14-18). Li (2020) showed that conditioned bulk density alone has R² > 0.9 with feed factor across four screw types (li2020predictiveperformanceof pages 49-53). These predictions can serve as physics-informed prior means, with the prediction residual variance as the prior variance, for a new powder whose material properties are measured but whose feeder behavior is unknown.

### Why Feed Factor Drifts 1.5–2× for the Same Material

The screw-feeder and loss-in-weight feeder literature identifies several mechanisms:

1. **Hopper fill level and head pressure**: As powder is discharged, the head pressure at the screw inlet decreases, altering how consistently screw flights fill. In funnel-flow hoppers, outlet stress decreases continuously with fill level, producing a characteristic feed-factor decay curve. In mass-flow hoppers, outlet stress remains more constant (fathollahi2024improvingcontinuouslossinweight pages 1-2, fathollahi2024improvingcontinuouslossinweight pages 2-4).

2. **Powder consolidation and densification**: Compressible powders densify under their own weight over time. Since the screw transports a fixed volume per revolution, increased density means increased mass per revolution (higher feed factor). Conversely, aeration from disturbance can temporarily lower density and feed factor (li2020predictiveperformanceof pages 66-73, li2020predictiveperformanceof pages 1-8).

3. **Refill events**: In loss-in-weight feeders, hopper refilling can compress the existing powder bed, forcing excess material into screw flights and producing overfeeding. Refill-induced disturbances are the largest documented source of feed-rate deviation (li2020predictiveperformanceof pages 66-73, engisch2014lossinweightfeedingin pages 134-139, engisch2014lossinweightfeedingin pages 1-7).

4. **Powder bridging, rat-holing, and screw coating**: Cohesive powders may bridge across the hopper outlet or rat-hole, intermittently starving the screw. Powder adhering to screw flights reduces effective flight volume (engisch2014lossinweightfeedingin pages 54-70).

5. **Moisture uptake**: For hygroscopic powders such as NaCl, moisture absorption increases bulk density, particle adhesion, and cohesion, all of which alter flow behavior. While not explicitly isolated in the studies reviewed, it is a well-known confound in pharmaceutical powder handling.

6. **Material buildup and headload variation**: Winski (2001) identifies material buildup on screw flights and headload variability as contributors to feeding performance drift (winski2001addressingfeedingperformance pages 2-3).

### Feed-Factor-vs-Fill-Level Calibration Practice

Pharmaceutical loss-in-weight feeder practice uses feed-factor profiles plotted against normalized hopper fill level. Bostijn et al. (2019) define FF_max (maximum feed factor) and FF_decay (the fill level at which FF drops to 90% of FF_max) as key material-specific response variables (bostijn2019amultivariateapproach pages 6-10, bostijn2019amultivariateapproach pages 10-14). The displacement-feed-factor concept of Fathollahi et al. (2020) tracks density variation during feeding via a material-specific curve that can be used to calibrate the system for accurate, constant feed rate (fathollahi2020performanceevaluationof pages 1-2). For this rig, the recommended practice is to measure or estimate cumulative dispensed mass as a proxy for fill-level depletion and to fit log(φ) against this covariate, making the 1.5–2× drift an explicitly modeled, predictable effect rather than unexplained noise.

## Q5. Tooling and a Portable Protocol

### Recommended Open-Source JAX Implementations

- **MAP optimization**: `optax` (gradient-based optimizers), `jaxopt` or `optimistix` (constrained optimization, Levenberg–Marquardt). These provide L-BFGS, Adam, and trust-region methods suitable for MAP fitting with autodiff gradients.
- **Differentiable ODEs**: `diffrax` for differentiable ODE/SDE integration in JAX, supporting event handling and adaptive stepping. Matei et al. (2025) demonstrate JAX/diffrax-based differentiable simulation through event-driven DAEs (matei2605differentiableparameteroptimization pages 1-2, matei2605differentiableparameteroptimization pages 2-4).
- **Differentiable Kalman filters and parameter learning**: `dynamax` provides JAX-native Kalman filtering, smoothing, and marginal-likelihood computation with automatic differentiation for parameter learning (linderman2025dynamaxapython pages 1-2, linderman2025dynamaxapython pages 2-4). It supports both maximum-likelihood and Bayesian inference for linear Gaussian state-space models.
- **Bayesian posterior sampling**: `numpyro` for probabilistic programming with NUTS/HMC and automatic Laplace approximation; `blackjax` for composable low-level MCMC/HMC/NUTS samplers in JAX (linderman2025dynamaxapython pages 1-2). Both are well-suited for sampling the posterior over 2–5 parameters given a differentiable log-density.
- **Whitehead group code**: `tsunamibayes` (GitHub) implements the random-walk Metropolis MCMC pipeline with GeoClaw forward models (ringer2021methodologicalreconstructionof pages 1-2, wonnacott2024methodologicalreconstructionof pages 7-9). Its architecture—explicit prior/likelihood specification with MCMC sampling over a modular forward model—is directly transferable to the doser, though the forward model would be replaced by the compartment model.

### Pitfalls of Differentiating Through Hybrid/Discontinuous Dynamics

The doser's start/stop dynamics, threshold-triggered halts, and Poisson-like clump arrivals create several challenges for automatic differentiation:

1. **Event-dependent gradients**: AD through hybrid dynamics produces gradients valid only for the particular event sequence selected by the forward simulation. If parameter changes alter the number, identity, or ordering of events (e.g., whether an arch breaks during or after a halt), the gradient becomes unreliable (matei2605differentiableparameteroptimization pages 1-2, matei2605differentiableparameteroptimization pages 2-4).

2. **Non-transversal crossings and grazing contacts**: Near event boundaries, gradients can be undefined or explosive. The standard remedy is to ensure transversal guard crossings and to segment the integration at event times (matei2605differentiableparameteroptimization pages 1-2, matei2605differentiableparameteroptimization pages 9-10).

3. **Discontinuous reset maps**: Halting the auger and triggering the tapper create state discontinuities. The discrete-adjoint approach treats these as equality constraints with Lagrange multipliers rather than penalizing them (matei2605differentiableparameteroptimization pages 9-10).

4. **Standard remedies**: (a) Use commanded rather than threshold-triggered stops in the calibration run to make halt times known inputs rather than functions of the estimated state. (b) Smooth hard switches with sigmoid or soft-max approximations (compliant-contact analogy) (newbury2024areviewof pages 10-11). (c) Use forward-mode AD (dual numbers) through event-handling code, which Rackauckas et al. (2021) show is robust and applicable to hybrid systems including event timing dependent on parameters (rackauckas2021acomparisonof pages 7-8). (d) Implement event-aware segmented integration with fixed scan lengths for JIT compatibility (matei2605differentiableparameteroptimization pages 2-4). (e) For stochastic clump arrivals, marginalize over the arrival process in the likelihood rather than trying to differentiate through random discrete events.

### Proposed "Calibrate a New Powder" Protocol and Parameter Card

**Minimal protocol** (10–15 minutes including loading):
1. Load powder into the tube-hopper assembly using a standardized fill procedure; record fill mass if feasible.
2. Measure bulk density, tapped density (Hausner ratio), and optionally d₅₀ of the powder.
3. Execute the multi-segment calibration run (6–10 segments, 3 RPM levels, varied durations, fixed tilt and tapping).
4. Run the MAP fit (φ first, then conditionally AF₀ and τ_af) with the stored population prior and a robust likelihood.
5. Compute profile likelihoods for each parameter; reject or pool parameters with non-identifiable profiles.
6. Store the parameter card.

**Per-powder parameter card contents**:
- Material identifier, lot, date, operator, environmental conditions (temperature, humidity)
- Measured material properties: bulk density, tapped density, Hausner ratio, d₅₀, moisture content
- Feed-factor estimate φ̂ (g/rev) with 95% posterior/profile CI at reference tilt and fill level
- Afterflow parameters AF₀ (mg) and τ_af (s) with CIs, or statement "not identifiable from this run"
- Process-noise and observation-noise scale estimates
- Fill-level covariate: initial fill, estimated fill at calibration, decay slope if measured
- Validity range: RPM range, tilt angle, fill-level range, time since calibration
- Re-calibration trigger: flag if cumulative dispensed mass exceeds X, or if closed-loop dose errors exceed 2σ of the stored posterior prediction, or if elapsed time exceeds the prior drift horizon

**Precedent**: Bostijn et al. (2019) demonstrate transferable powder characterization via a multivariate material-property database linked to feeder performance predictions (bostijn2019amultivariateapproach pages 6-10, bostijn2019amultivariateapproach pages 1-6). Li (2020) shows conditioned bulk density alone predicts feed factor with R² > 0.9 (li2020predictiveperformanceof pages 49-53). Van Snick et al. (2018, cited in Bostijn) built a multivariate raw-material-property database for pharmaceutical continuous manufacturing.

### Summary Verdict

The proposal to fit (φ, AF₀, τ_af) from a single run using autodiff MAP with a Gaussian prior is sound in principle and is equivalent to strong-constraint 4D-Var with a background term (ebtehaj2013onvariationaldownscaling pages 20-22, frion2026addaamodular pages 4-5, freitag2013synergyofinverse pages 1-4). However, it should be implemented with three modifications grounded in the literature: (1) use a robust (non-Gaussian) residual model to handle granular jump noise, (2) verify Laplace uncertainty estimates against profile likelihoods before trusting them, and (3) treat stored values as session priors with growing variance rather than constants. The strongest production estimator is a differentiable Kalman-filter marginal likelihood that integrates out latent states, with offline HMC for validation. Online CDA-style parameter adaptation should be deferred until offline estimates prove stable and the single-sensor, hybrid-dynamics limitations are addressed. Making hopper fill level observable and modeling feed-factor-vs-fill is the single highest-impact hardware/modeling change for reducing the dominant 1.5–2× drift.
