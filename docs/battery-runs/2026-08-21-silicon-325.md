## Results

**Block A** — 8 no-actuation reads, every one exactly 0.0000 g.

**Block B** — 15 s static holds at 0°, 45° and 90°, every one exactly 0.0000 g.
Eleventh powder in a row that does not avalanche through a stationary auger even
fully vertical, and the first time that has been measured against a 0.0 mg floor.

**Block C — feed factor vs tilt** (6 × 360° at 30 RPM per tilt):

| tilt | mg / revolution | revolutions 1–6 (mg) |
|---|---|---|
| 0° | **≤ 0.1** (all zero) | 0, 0, 0, 0, 0, 0 |
| 45° | **≤ 0.1** (all zero) | 0, 0, 0, 0, 0, 0 |
| 90° | **1.20** (RSD 245 %) | 0, 0, 0, 0, 0, 7.2 |

**17 of 18 revolutions delivered exactly 0.0000 g.** The single 7.2 mg event is
an isolated release, not a rate — the same shape brown rice flour showed, and
the mean is an average over a process that is mostly nothing.

**Block D — speed** (3 continuous revolutions at tilt 45°): 21.4 / 14.0 /
17.0 mg at 15 / 45 / 90 RPM, i.e. **7.1 / 4.7 / 5.7 mg per revolution**. No
usable speed trend (RSD 21 % on three points spanning 6× in speed).

**Block E** — re-feed rotations 0.31 mg/rev at 0° and 1.10 mg/rev at 45°; taps
−0.04 mg at 0° and 0.55 mg at 45°, both with RSD > 170 %. Tap quantum **not
resolved** — but for the opposite reason to the last three runs: here the
baseline is a hard 0.0 mg and the *taps themselves* are at the resolution
floor, so this is a real bound rather than a room-limited one.

**Block G** — 3 × 1.000 g, frozen salt-tuned controller: all three `stalled`
at 0.0000 / 0.0016 / 0.0004 g in 6–7 s, 13.7 auger revolutions total, 0 taps.
The bulk phase's no-flow detector fires almost immediately, as it did for brown
rice flour.

**Total delivered across all 64 trials: 75.0 mg.** AlSi10Mg on the same rig
five hours earlier used 15 g.

## The controlled comparison

| | silicon −110/+200 (75–150 µm) | silicon −325 (< 44 µm) |
|---|---|---|
| run | 2026-08-20 15:48 MDT | 2026-08-21 10:18 MDT |
| block C @ 0° | 57.2 mg/rev | ≤ 0.1 |
| block C @ 45° | 210.7 mg/rev | ≤ 0.1 |
| block C @ 90° | **302.4 mg/rev** | **1.2** |
| block B, all tilts | no discharge | no discharge |
| 1 g doses | not run | 3 × stalled |

Same element, same rig, same frozen parameters, same operator, 22 hours apart.
Every powder in the dataset differs from every other in chemistry, morphology
*and* size at once; this pair differs deliberately in size alone, and spans
roughly **250×** in feed factor — most of the dataset's three-decade range.

That is the expected direction: below roughly 50 µm, interparticle cohesion
overtakes gravity, and a screw meters what falls into its flights. Stated as a
mechanism it is a hypothesis this run cannot prove — n = 1 per cut, one auger
each, and no independent particle-size or flowability characterisation. Stated
as an observation it is the cleanest controlled contrast the dataset has.

## QC — recorded valid, as an upper bound

The run was captured excluded (the default) and promoted after review, via
`scripts/amend_battery_run.py` so the original assessment and the reason are
both preserved. Every rig-side explanation is eliminated:

| candidate fault | status |
|---|---|
| outlet taped or capped | eliminated — camera frame, and the diagnostic conveys |
| flights still charging | eliminated — flat over 45 revolutions |
| balance noise swamping the signal | eliminated — block A σ = 0.0 mg, 0 shocks |
| bench disturbance | eliminated — 64/64 clean trials, 0 retries |
| tilt axis stuck (the 2026-08-11 fault) | eliminated — the tilt curve is not flat, and the servos were verified on camera 2026-08-19 |

Three caveats travel with the row and are recorded in `qc` and in the
amendment rather than folded away:

1. **Block C is confounded with run order.** 0° and 45° ran first and read a
   hard zero; block D at the same 45° minutes later conveyed 4.7–7.1 mg/rev.
   Every block C figure is an upper bound, not a point estimate.
2. **The block C / block E consistency check fails.** At 45°, C = 0.0 mg/rev
   and E's re-feed = 1.10 mg/rev, so the ratio every conveying run holds at
   0.74–1.12 is undefined here. Do not read per-tilt feed factors as
   comparable point estimates for this powder.
3. **Powder and auger are not yet separated.** This auger has never been shown
   to convey anything. The decisive control is to load silicon −325 into the
   auger that conveyed silicon −110/+200 at 302 mg/rev — that holds the auger
   fixed and varies only particle size. Brown rice flour needed the mirror of
   this test (a second auger) before its zero was believed.

Also noted: `qc.preflight_verdict` is `null` because the embedded pre-flight
document nests its verdicts under `preflight` / `diagnostic` rather than at top
level. Both verdicts are present under `run.preflight`.
