## Conventions

- One `.md` per video, plus a sibling directory of the same name holding `images/` and the raw
  machine transcripts used to build the corrected one.
- Screenshot filenames are `<mmss>-<slug>.jpg`; the exact source timestamp is also burned into
  the bottom-left of each frame so a screenshot is self-identifying once copied out of the repo.
- Block quotes are the video; "Actionable" paragraphs are analysis and are labelled as such.
- Each write-up ends with a provenance appendix recording how the video was obtained and how the
  transcript was reconciled.
